03

填入地址与可用模型

兼容客户端 Base URL：
https://api.thisai.site/v1
模型 ID 请使用当前分组实际可用的名称。

REQUEST EXAMPLE / cURL
# 替换密钥和模型 ID 后再运行
curl https://api.thisai.site/v1/responses \
  -H "Authorization: Bearer THISAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "input": "你好，ThisAI。",
    "stream": true
  }'

仅为 Responses 接口示例；接口与模型支持范围以账号分组的实际配置为准。

A FEW THINGS TO KNOW

开始前，
你可能想了解。

把常见问题讲清楚，
让每一次接入少一点猜测。

我可以使用哪些模型？+

可用模型取决于你已开通的分组及站点配置。请在控制台确认后填写模型 ID；首页不代表所有模型都已开放。

现有的 AI 工具可以直接接入吗？+

支持自定义兼容 API 地址的工具通常可以配置接入。填入 Base URL 和 ThisAI API Key，并确认工具使用的接口与模型在当前分组中受支持。

如何查看余额和使用情况？+

登录控制台查看账户余额、用量统计和请求记录。具体计费、额度和购买方式以站点规则及控制台展示为准。

API Key 可以放在前端网页里吗？+

不建议。前端代码、浏览器请求和公开仓库都可能暴露密钥。请在服务端或可信的本地环境中使用，并定期检查密钥与用量记录。
